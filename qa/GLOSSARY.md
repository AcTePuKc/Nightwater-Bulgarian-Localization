# QA глосар и правила за одита на българския превод

Игра: **Isle of Industry** (Unreal проект `SkylandsForaging`), жанр: фабрична
автоматизация с прибиране на ресурси. Тон: неформален, разговорен, но ясен за UI.

Обхват на одита: 1155 реда от `working/Game.bg.json` (полета `key`, `source`, `target`).

## 1. Утвърдени термини

Тези преводи идват от предишен човешки преглед и са записани в
`tools/repair-draft-qa.py`. Одитът ги приема за правилни и маркира всяко
отклонение от тях.

| English | Утвърден български | Бележка |
|---|---|---|
| Plant Farmer | Растителна ферма | сграда/машина, не професия |
| Harvester / Auto-Harvester (сграда) | Автоматичен събирач | да не се смесва с Collector |
| Collector (устройство, което играчът задейства) | Събирател | отделно от Harvester |
| Rock Crusher | Каменотрошачка | |
| Pulverizer | отделен термин | да не се слива с Rock Crusher |
| Blessing / Blessings | Благословия / Благословии | |
| Upgrades | Подобрения | |
| Credits | кредити | |
| Player (в текстове) | играч | |

## 2. Предложени за утвърждаване

Одитът **маркира** несъответствията, но **не налага** тези решения — те чакат
потвърждение от човека. Използвай ги само за да прецениш дали даден ред е
несъответствие.

| English | Предложение | Какво е положението в момента |
|---|---|---|
| Milestone | Етап | 4 варианта: „етап“ (22×), „постижение“, „Междинна цел“ и несъществуващата дума „преметница“ |
| Dark Thicket | Мрачният гъсталак | 4+ варианта: „Мрачната гъсталака“, „Тъмния гъсталак“, „Мрачния гъст лес“, „Тъмната гъсталака“; „гъсталака“ е и грешен род |
| run (едно преминаване) | рунд | сега и „рунд“, и буквалното „бягане“ |
| Buffs | Бонуси | сега се слива с Upgrades → „Подобрения“ |
| Dash | Ускорение | сега „Скок“, което се слива с Jump |
| Jump | Скок | |
| Harvester (като дума в текстове) | Автоматичен събирач | в текста още „дървосекач“, „секач“, „фермер“ |

## 3. Обръщение към играча

Преобладава **неформалното единствено число** („ти“): в предишния преглед има
26 неформални императива и 0 официални. Одитът приема „ти“ за норма.

Маркирай като несъответствие всеки **официален/множествен императив**
(„Спечелете“, „Платете“, „Оборудвайте“, „Напредвайте“…) и всяко „вие/ви/ваш“.
Внимание: думи като „цвете“, „слотовете“, „можете“ не са императиви — прецени
по формата, не по окончанието.

## 4. Какво НЕ е дефект

- Термини, които играта съзнателно оставя на английски: `Berserk`, `Bit & Hogg`,
  `Gaia`, `VSync`, `Chelsea Market`, `Robin`, имена на герои и места от сюжета.
- Чисто пунктуационни низове (`...`, `-`, `:`).
- Плейсхолдъри (`{Amount}`, `{AoERange}`…), rich-text тагове и `\r\n` —
  проверени машинно: 0 разминавания. Ако все пак видиш счупен такъв, маркирай го.
- Диалектни/разговорни форми, ако звучат естествено на български.

## 5. Тежест

| severity | Кога |
|---|---|
| `critical` | грешен смисъл; непреведен или чужд език; счупен плейсхолдър; объркан ключов термин (напр. две различни сгради с еднакъв превод) |
| `major` | неточен превод; измислена дума; граматическа грешка, която променя смисъла; разминаване в обръщението; неутвърден вариант на утвърден термин |
| `minor` | тромава формулировка; стил; пунктуация; подозрителна дължина за UI |

## 6. Категории

`untranslated` · `foreign` · `mistranslation` · `terminology` · `consistency` ·
`grammar` · `style` · `length`

## 7. Формат на находките

Всяка находка се отнася до **един** ред и съдържа индекса му `i` от входния
файл. Текстът на `issue` и `suggestion` е на български.

```json
{
  "i": 250,
  "key": "/9663718E4482BA8F1266D28DCCFFA9A7",
  "severity": "critical",
  "category": "untranslated",
  "en": "Crystal Dust",
  "bg": "Kristalna prašina",
  "issue": "Редът е останал на босненски, не е преведен на български.",
  "suggestion": "Кристален прах"
}
```

Правила:
- Не измисляй находки. Ако един ред е добър, не се обаждай за него.
- Един ред може да има няколко находки, ако има няколко отделни проблема.
- `suggestion` винаги е готов за подмяна български текст със запазени
  плейсхолдъри и нови редове.
- Не предлагай промени, които чупят `{}` плейсхолдъри или `\r\n`.
